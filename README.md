# PPTX to Scheme of Work Converter

Browser-based tool for convertin-g lesson PowerPoints into a formatted Scheme of Work spreadsheet.

## Privacy

All processing happens locally in the browser. Uploaded PPTX files are not sent to a server.

## Use

Open the GitHub Pages site, upload a `.pptx` file, review the extracted table, edit if needed, then download the `.xlsx`.

## Notes

This is a prototype. Maths equation extraction is still being improved, especially for complex Office Math fractions.
